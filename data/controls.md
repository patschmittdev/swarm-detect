# Independent controls

Models and thresholds are from the main by-run split; neither control sweep is used for fitting or calibration. Every k-of-n rate uses a 95% Wilson interval. Each row names seed, main split and its fitting/calibration/test class counts. Independent benign test runs are all controls; independent loud test runs are all positive. BOTH V1 aggregation detectors must flag every loud run at the calibrated threshold and score it strictly above every calibration control with benign_sharing_teams == 0. Logistic must also beat every calibration control. Boosted's all-controls strict bar is non-gating and is reported separately below with its measured outcome. The rule baseline has no gating bars: its rows, including its three bar comparisons, are diagnostics, and it never affects the reproduce exit status. Ties fail each strict comparison. Sharing metadata is taken only from recorded main-run conditions to select comparison controls after fitting and calibration; it never enters a detector. All loud scores and bars are full-trace measurements, including when repeated beside online benign FPR. Other tier/family rows are diagnostics.
